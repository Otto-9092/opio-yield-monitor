# 1480 Clean Grain Elevator — Recon Photos
Date: 24 August 2026
Combine: 1979 Case IH 1480
Project: opio-yield-monitor (Phase 1 recon)

## Note on image size

Photos were resized to 1600px on the long edge (from ~4000px originals) to keep
the repo lean. Details on tape measures, part markings, and clearances are still
sharp. If you need the untouched originals, they're in the chat history where
they were uploaded.

## Folder structure

- `01_combine_overview/` — Wide shots showing which side of the machine we're on
- `02_elevator_top/` — Head housing area with the discharge/unloading tube
- `03_housing_dimensions/` — Exterior housing measurements with tape
- `04_drive_system/` — Head-shaft drive chain and sprocket
- `05_top_distributor/` — Rotary distributor at very top (chain-driven, tension springs)
- `06_paddle_chain_interior/` — Views into the paddle chain through the access opening
- `07_access_opening_dims/` — Interior measurements at the access opening (critical for sensor bracket sizing)
- `08_paddle_geometry/` — Paddle thickness and clearance measurements
- `09_head_shaft/` — Head shaft / bearing housing measurement

## Categorization is provisional

Vylor Chat categorized these by visual inspection from photo previews. If any
are miscategorized, rename freely — the important thing is the raw data is
organized enough to work with.
